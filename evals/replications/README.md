# Study-Level Reanalyses

Each directory contains one AERIS source-substitution reanalysis attempt. The
execution record retains the public-input acquisition code, AERIS exposure
code, model code, source manifest, tool trace, coverage diagnostics, and a
result note.

The study-specific instructions are summarized in
[`../docs/REPLICATION_PROMPT_SUMMARIES.md`](../docs/REPLICATION_PROMPT_SUMMARIES.md).
The primary executable entry points are listed in
[`../docs/CODE_INVENTORY.md`](../docs/CODE_INVENTORY.md).

Completed fits and documented failures are both part of the record. Consult
each study's `README.md`, `REPLICATION.md`, and `RESULT.md` for its target,
substitutions, commands, and current outcome.
