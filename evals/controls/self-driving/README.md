# 2. Self-driving AERIS

Three independent nine-study campaigns used frozen self-driving AERIS with no
human scientific intervention. They produced 23 fitted analyses in 27 attempts.

- `AERIS-self-driving-summary.json`: completion, runtime, and token use by campaign.
- `AERIS-self-driving-study-results.csv`: every study attempt.
- `AERIS-self-driving-effect-agreement-summary.json`: aggregate effect agreement.
- `AERIS-self-driving-effect-comparisons.csv`: comparable fitted contrasts.
- `Protocol and runs/analysis/run-registry/`: transcripts, generated code,
  results, and manifests for all attempts.
- `Protocol and runs/`: frozen prompts, policies, schemas, and validators.
