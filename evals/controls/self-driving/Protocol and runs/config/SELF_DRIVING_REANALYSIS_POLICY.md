# Self-driving reanalysis policy

Version: 2.0. Freeze this file with each campaign.

## Objective

Complete the strongest defensible source-substitution reanalysis supported by
the public record. Preserve the article's scientific question and record every
material difference from its analysis. Prior replication code, source routes,
exposure values, and fitted results are prohibited.

## Standing authority

The agent may retrieve lawful public data, inspect sites and endpoints, use
verified mirrors, install bounded open-source parsers, write and run code,
resume deterministic batches, choose defensible implementation details, repair
failures, and continue within the frozen safety envelope. Existing approved
credentials may be used for their intended services.

Intervention is reserved for restricted data, missing credentials, paid access
beyond budget, unsafe operations, exhausted resources, or an indefensible
scientific change. A failed route does not establish unavailable data.

## Scientific contract

The initial contract protects the research question, outcome and population,
pollutant, principal contrast, broad geography and period, prohibited evidence,
and resource ceilings. Retrieval routes, source URLs, stations, coverage
subsets, optional covariates, and implementation choices remain open during
exploration.

Amendments are append-only. Each records the evidence, changed dimension,
scientific reason, fidelity impact, and confirmation that agreement with the
published estimate played no role. Changes to an invariant require a construct
change or supported-sensitivity label.

## Execution

1. Recover the complete article, supplements, and data-availability statement.
2. Inspect named sources and plausible public recovery routes.
3. Build a minimal valid outcome-exposure slice to test feasibility.
4. Finalize the executable design from evidence through AERIS's append-only
   contract amendment.
5. Retrieve the complete eligible sample with checkpoints and diagnostics.
6. Fit and validate the strongest supported analysis.
7. Challenge geography, coverage, estimand, transformations, source fidelity,
   and model validity; repair actionable weaknesses and repeat.

A probe estimates feasibility or cost. It cannot exclude a unit or become a
terminal scientific conclusion. Coverage is reported for every eligible unit.
A numeric exclusion threshold requires support from the article or measurement
source.

## AERIS role

Every fitted analysis uses AERIS for exposure design, source or monitor
discovery where applicable, spatial and temporal assignment, exposure
computation or integration of independently recovered public observations,
coverage diagnostics, provenance, decisions, and analysis handoff. The host may
use web, shell, generated code, and public sources freely.

## Durable evidence

Maintain a research notebook with the current objective and invariants,
evidence, hypotheses, attempted routes, decisions, blockers, and next actions.
Preserve source requests, responses, files, checksums, transformations,
coverage, code, model output, and failed routes.

A terminal blocker requires executable attempts. Each attempt records a URL or
command, response status or error, bytes or records returned, format or schema
inspection, and a saved evidence artifact. Applicable archive, mirror,
successor, regulator, batching, and article-supported fallback routes must be
tested before stopping.

An article-named exposure provider remains applicable when a homepage requires
authentication. Inspect public forms, scripts, request targets, reports,
archives, and legacy interfaces. If JavaScript assigns a form action, fetch the
linked script and exercise the generated request. A catalog or landing page is route evidence,
not retrieved scientific data. Search failed bulk files by exact basename and
path fragments, then inspect public clients, code, mirrors, and successor
systems for lawful access to the same records.
An authenticated code-search API does not complete a mirror search; continue
through ordinary web search, repository pages, package registries, source
archives, public clients, and documentation. Follow plausible search results;
the results page alone does not complete recovery.

Treat the first valid terminal blocker as provisional. A fresh reasoning pass
must reload the durable work, try to falsify each remaining blocker, and build
a minimal valid outcome-exposure slice wherever a lawful public route supports
one. Keep the locked scientific target and safety limits unchanged.

## Completion

Report the strongest completed analysis with its fidelity level and deviations,
or an evidenced stop. Express fitted effects on the article's contrast. Never
choose a source, subset, transformation, or model because it agrees better with
the published estimate.
