# Decisions

- Reconstructed the published design from the supplied article: US county/county-equivalent cross-sectional regressions, 2016–2020, annual PM2.5 (ug/m3), and ischemic and hemorrhagic stroke mortality among adults 65+. The primary comparison was defined as the all-county adjusted ischemic-stroke coefficient per +1 ug/m3 PM2.5; the parallel hemorrhagic comparison and manuscript subgroup comparisons were secondary.
- The published adjusted model contains PM2.5 plus CAD, hypertension, hyperlipidemia, diabetes, obesity, smoking, median household income, Gini index, poverty, uninsured, and park access. The unit is a county rate (deaths per 100,000), so its coefficient is a rate difference, not an OR/RR. A positive ratio transformation is not mathematically identified for this linear model without a specified baseline/link.
- Retrieved the independent EPA AQS 2020 daily PM2.5 (parameter 88101) release and made a transparent monitor-county assignment. It produced 625 county FIPS (626 rows including header). This is not author exposure data and is not treated as population-weighted county exposure.
- Retrieved CDC Atlas dataset `g5fg-bgtw` to test whether it could supply the target outcome. Its own fields/metadata identify all-stroke mortality for adults 35+, 2018–2020 3-year age-adjusted and spatially smoothed rates. It cannot stand in for either target outcome; it was never joined or modeled.
- Attempted CDC WONDER D176 for the exact mortality construct. The endpoint returned HTTP 500. Per retry policy, this was documented and an alternative public release of the same outcome construct was sought; the accessible Atlas release failed compatibility review.
- No author-designated outcome/covariate table was used. `code/reanalysis.py` provides a sanitization function that drops pollution, exposure, air-quality, fitted, prediction, residual, model, and attributable fields before rows are inspected or modeled. `sanitization_audit.json` records the non-use and empty retained/dropped sets.
- Did not fit a reduced, proxy-outcome, monitor-only, or covariate-omitted regression. That would silently change outcome, period, exposure assignment, coverage, and model.
