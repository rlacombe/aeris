# Blocker ledger

No terminal blocker. The public inputs supported a fitted 36-country, two-timepoint reconstruction.

Declared fidelity limitations:

- WHO's exact 2020 daily extract was not used; JHU CSSE country totals are a source substitution.
- Legacy World Bank values and author fallback selections cannot be guaranteed to match the values visible at the time of publication. These are disclosed in `fidelity_record.json`.
- The exact Table-1 `PM2.5 exposure` variable was not modeled because the independent-source requirement governs exposure reconstruction. The independent concentration measure is retained.
