# 3. Raw-agent ablation

The same model attempted the same nine studies in three independent campaigns
without AERIS tools, instructions, or exposure engine. It produced 3, 3, and 1
fitted analyses: seven fits in 27 attempts.

- `raw-agent-three-campaign-summary.json`: aggregate result and effect metrics.
- `codex-baseline*-batch.tsv`: campaign ledgers.
- [`RUNS.md`](RUNS.md): direct links to all 27 attempt records.

The median absolute log-effect difference of 0.073 describes only the seven
completed fits. It does not account for the 20 attempts that produced no fit.
